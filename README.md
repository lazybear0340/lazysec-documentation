# LazySec

## The best free, secure, mobile-supported obfuscator for executors

LazySec is a next-generation obfuscator built for Roblox Luau scripts. It is designed to protect scripts without unnecessary friction while remaining accessible across desktop and mobile workflows.

## Why LazySec?

- **Free** — powerful script protection without a paywall
- **Executor-focused** — built for Roblox Luau and executor workflows
- **Mobile supported** — use LazySec from supported mobile setups
- **Secure** — protection designed to resist static analysis, decompilation, and automated deobfuscation
- **Low performance cost** — optimized transformations help keep runtime overhead low

## Protection features

- **Custom macro SDK** — create custom obfuscation macros and transformations
- **Multi-layer transforms** — combine control-flow flattening, variable renaming, string encoding, and dead-code injection
- **Advanced virtual machine** — bytecode-level protection designed to resist static analysis and emulation
- **Anti-debug traps** — runtime guards that detect and disrupt debugging attempts
- **Static resistance** — hardens scripts against decompilation and automated analysis
